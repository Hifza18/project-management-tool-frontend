# Project Management Tool

A full-stack Project Management Tool that allows users to create projects, manage tasks, track task progress, and collaborate through comments.

## ✨ Features

- User Registration
- User Login & Authentication
- JWT Authentication
- Create Projects
- View Projects
- Create Tasks
- Edit Tasks
- Delete Tasks
- Task Priority
- Task Due Dates
- Task Status Management
- To Do / In Progress / Completed
- Task Comments
- Dashboard Statistics
- Logout
- Responsive Interface

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- JWT
- bcryptjs

### Database
- PostgreSQL
- Supabase

### Deployment
- Frontend: Vercel
- Backend: Render
